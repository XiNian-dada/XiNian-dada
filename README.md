## About Me

你好，我是 **XiNian_dada**。

目前专注于 **嵌入式开发、底层系统级工程与软硬件协同（Embedded & Systems Programming）**。  
坚持从真实需求出发，不喜无意义练习或过度包装的项目，倾向于 **软硬兼施、有需求就写、有问题就修**。

主要专注领域：
- **嵌入式与硬件交互**：基于 ARM Linux 板卡（如 RK3399）与单片机（ESP32 / STM32）进行外设驱动、USB Gadget (OTG)、V4L2 硬件视频采集与电路控制。
- **Rust 系统级工程**：开发低资源开销、高并发吞吐的系统服务、监控 Agent 与后台守护进程。
- **网络与固件扩展**：针对 OpenWrt 固件、Linux 网络栈（nftables / WireGuard）定制流量转发与代理网关。

## 100 Libraries Challenge

我在进行一个长期的个人挑战：

> **三年内完成 100 个真正可用的开源项目与代码库**

每个项目都遵循三个基本原则：
1. **真实可用**：解决具体真实的工程场景或个人需求，不做半成品 Demo。
2. **文档自洽**：开箱即用，具备详尽的部署或接入说明。
3. **软硬结合**：既有底层硬件的控制驱动，也有现代系统级架构的打磨。
